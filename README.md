# Trefort9k

## Prog mappa – félév végi felzárkóztató terv (HTML/CSS alapok)
1. **Alap HTML ismétlés (2×45 perc)** – doctype, `<html>`, `<head>`, `<body>`, címkék jelentése; szövegformázás (`<h1>`–`<h6>`, `<p>`, `<b>`, `<i>`, `<u>`).
2. **Listák és hierarchia (1×45 perc)** – rendezetlen/rendezett listák (`<ul>`, `<ol>`, `<li>`), többszintű listák; gyakorló feladat: kedvenc sportok több szinttel.
3. **Táblázatok (1×45 perc)** – `<table>`, `<tr>`, `<th>`, `<td>`, szegélyek, `border-collapse`; gyakorló feladat: ponttáblázat készítése.
4. **Képek és hivatkozások (1×45 perc)** – `<img>` forrásmegadás (helyi fájl vs. URL), `alt` használata; `<a>` linkek, célra ugrás `id`-vel.
5. **Alap CSS (2×45 perc)** – külső stíluslap linkelése, alap szöveg- és háttérstílusok, listák és táblázatok formázása; gyakorló feladat: egyszerű landing page.
6. **Elrendezés és reszponzivitás (1×45 perc)** – blokk/inline elemek, alap flex vagy float; képek méretezése mobilra.
7. **Mini projekt (2×45 perc)** – önálló oldal (pl. recept vagy bemutatkozás) HTML + CSS-sel, tanult elemek használata, tanári visszajelzés.
8. **Önellenőrzés (házi)** – röpdolgozat minták újraírása (listaszerkezet, kép + táblázat + link), majd W3C validator próba.

> A fenti sorrend a `prog` mappában található feladatokra épít (listák, táblázatok, képek, alap CSS, belső ugrólinkek). Minden órán legyen 15 perc gyakorló feladat és 5 perc önellenőrzés.
