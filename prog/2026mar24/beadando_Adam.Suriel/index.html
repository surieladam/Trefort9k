Hogyan működnek a CSS class-ok?

Class használat: egy CSS szabálycsoportot egyszerre több elemre alkalmazunk. class="classattributum" és class="fontos" a kinézetet csoportosan változtatja, az HTML építése közben olvasható marad.

Mi történik akkor, ha egy elem nem kap class attribútumot?

Ez a szöveg nem rendelkezik class attribútummal. A megjelenése kizárólag az alapértelmezett, illetve a HTML taghez tartozó CSS szabályoktól függ. Ilyenkor minden ilyen elem ugyanolyan kinézetű lesz.

Mi történik akkor, ha egy elem kap class attribútumot?

Ez a szöveg már tartalmaz class attribútumot. A class segítségével több HTML elemet tudunk egy csoportba sorolni. Ha később CSS-ben erre a class-ra hivatkozunk, minden ilyen elem egyszerre fog megváltozni.

Ez egy másik szöveg, amely ugyanazt a class attribútumot használja. Emiatt a két elem megjelenése megegyezik, még akkor is, ha a tartalmuk eltérő.

Miért fontos a class használata?

A class segítségével elkerülhető, hogy minden elemet külön-külön kelljen formázni. Ezt akkor használjuk, ha ugyanazt a formázást többször is alkalmazni szeretnénk az oldalon, így átláthatóbb kódot kapunk.
