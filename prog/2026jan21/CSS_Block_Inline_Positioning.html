1️⃣ Block vs Inline - Alapok

🔵 Block elemek (block)

Jellemzői:

  • Teljes szélességet foglal el (100% width)
  • Új sorban kezdődik
  • Új sorban végződik
  • Margin, padding, border, width, height - mindez módosítható
  • Alapértelmezett html elemek: <div>, <p>, <h1-h6>, <section>, <header>, <footer>, <ul>

Vizuális demó - Block elemek:

🟢 Inline elemek (inline)

Jellemzői:

  • Csak annyit foglal el, amennyi a tartalma
  • Ugyanabban a sorban helyezkedik el más elemek mellett
  • Bal/jobb margin és padding működik, de TOP/BOTTOM nem!
  • Width és height nem módosítható
  • Alapértelmezett html elemek: <span>, <a>, <strong>, <em>, <img>

🟡 Inline-Block

Kombinálja a block és inline tulajdonságait:

  • Ugyanabban a sorban helyezkedik el, mint az inline
  • DE: width, height, margin és padding mindegyike módosítható!

2️⃣ Display CSS - Értékek

📌 A display tulajdonság határozza meg, hogy az elem hogyan jelenjen meg az oldalon.
Display érték Leírás Praktikus használat
block Új sorban, teljes szélesség Fő tartalmak, bekezdések, fejlécek
inline Ugyanabban a sorban, csak szükséges hely Szövegformázás (bold, italic)
inline-block Inline szerű, de módosítható méret Gomb, ikon, kisebb dobok
flex Rugalmas elrendezés (soron vagy oszlopban) Menü, gombok csoportja, elrendezés
grid Rácsos elrendezés (sorok és oszlopok) Összetett elrendezés, galériák
none Elem nem jelenik meg Elemek elrejtése
/* Alapvető display értékek */
selector {
  display: block;
}

3️⃣ Box Modell - Alapvető koncepció

Minden HTML elem egy "dobozból" áll, ami 4 részre osztható:

📦 Box Model szerkezet (kívülről befelé):

  1. Margin - A doboz körüli külső tér (gennyira van az elemtől)
  2. Border - A doboz kerete
  3. Padding - A tartalom körüli belső tér (a border és a tartalom között)
  4. Content - A tényleges tartalom (szöveg, képek stb.)

📏 Box-sizing értékek

1. content-box (alapértelmezett)

Width és Height CSAK a tartalomra vonatkozik.

A padding és border HOZZÁADÓDIK a szélességhez!

div {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}

/* Valódi szélesség = 200 + 20 + 20 + 5 + 5 = 250px */

2. border-box

Width és Height tartalmazza a paddingot és a bordert is!

Ez a modern és ajánlott megoldás!

div {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}

/* Valódi szélesség = 200px (tartalmaz mindent) */
✅ Ajánlás: Szinte mindig használj box-sizing: border-box; a * selectorral az oldal tetején!
* {
  box-sizing: border-box;
}

4️⃣ Box-shadow - Árnyék effektek

Szintaxis: box-shadow: offset-x offset-y blur-radius spread-radius color inset;

🎨 Box-shadow paraméterek

Paraméter Leírás Érték
offset-x Árnyék jobbra eltolása Pozitív = jobbra, negatív = balra
offset-y Árnyék lefelé eltolása Pozitív = le, negatív = fel
blur-radius Árnyék elmosódottságának mértéke Nagyobb szám = többféle árnyék
spread-radius Árnyék kiterjedésének nagysága Pozitív = nagyobb, negatív = kisebb
color Árnyék színe rgba(0,0,0,0.3) vagy #000
inset Belső árnyék a dobozban Opcionális kulcsszó

📌 Box-shadow Praktikus Példák

1. Egyszerű árnyék (offset-x, offset-y, blur):

✨ 5px-es offset jobbra és le, 10px-es blur
div {
  box-shadow: 5px 5px 10px rgba(0,0,0,0.3);
}

2. Blur effect - Fényes szín, elmosódott árnyék:

💫 Elmosódott, kékes árnyék
div {
  box-shadow: 0 0 20px rgba(102,126,234,0.6);
}

3. Spread effect - Kiterjesztett árnyék:

📦 Kiterjesztett árnyék körülötte
div {
  box-shadow: 0 0 0 10px rgba(102,126,234,0.3);
}

4. Inset - Belső árnyék:

🔘 Belső árnyék a dobozban
div {
  box-shadow: inset 0 0 10px rgba(0,0,0,0.2);
}
💡 Tipp: Több árnyékot is lehet egymás után írni vesszővel elválasztva!
box-shadow: 0 0 10px rgba(0,0,0,0.3), inset 0 0 5px rgba(0,0,0,0.1);

5️⃣ Position - Pozicionálás módok

📌 A position tulajdonság határozza meg, hogy az elem hogyan helyezkedik el az oldalon.

🔵 Static (alapértelmezett)

Jellemzői:

  • Normális dokumentum folyamban helyezkedik el
  • A top, bottom, left, right tulajdonságoknak nincs hatása
  • Ez a default érték minden elemnek
📍 Static position - normális helyen
div {
  position: static;
  top: 100px; /* Ennek nincs hatása! */
}

🟡 Relative

Jellemzői:

  • Az elem eredeti helyétől eltolható (top, bottom, left, right)
  • Az eredeti hely foglalt marad (más elemek nem helyezkednek oda)
  • Relatív pozicionálás = az elem saját pozíciójához viszonyított

Normális elem:

📍 Normális elem - nem mozgatott

Relative element (20px jobbra, 10px le):

📍 Relative - eltolt az eredetitől
div {
  position: relative;
  left: 20px;
  top: 10px;
}

🔴 Absolute

Jellemzői:

  • Az elem kikerül a normális dokumentum folyamából
  • Az eredeti hely felszabadul (más elemek oda helyezkednek)
  • A legközelebbi pozícionált szülőhöz viszonyítva helyezkedik el
  • Ha nincs pozícionált szülő, az oldal tetejétől számít

Szülő elem (position: relative):

Ez a szülő elem

📍 Absolute - jobb felső sarok

Ez maradt az eredeti helyen, mert az absolute elem kikerült az áramlásból

szülő-div {
  position: relative;
}

gyermek-div {
  position: absolute;
  top: 10px;
  right: 10px;
}

🟢 Fixed

Jellemzői:

  • Az elem a viewport-hoz (a képernyőhöz) rögzítve marad
  • Görgetéskor az elem nem mozdul el
  • Tökéletes: navigációs menü, lebegő gombok, stb.
⚠️ Fixed position! Az alábbi elem a képernyő jobb alsó sarkában marad még akkor is, ha görgetsz.
📍 Fixed - görgetéskor mozdulatlan
div {
  position: fixed;
  bottom: 20px;
  right: 20px;
  z-index: 1000; /* Hogy felül legyen */
}

🔵 Sticky

Jellemzői:

  • Kezdetben static-ként viselkedik
  • Görgetéskor, amikor eléri a megadott pozíciót, fixed lesz
  • Szülő elemhez van kötve (nem az egész viewport-hoz)
📍 Sticky - marad a tetején, amikor görgetsz

6️⃣ Position Értékek Összehasonlítása

Position Normális áramlás top/bottom/left/right Viszonyítva Például
static ✅ Igen ❌ Nincs hatás — Normális elem
relative ✅ Igen ✅ Igen Eredeti helye Elem eltolása
absolute ❌ Nem ✅ Igen Szülő elem Modal, tooltip
fixed ❌ Nem ✅ Igen Viewport (képernyő) Lebegő gomb, navbar
sticky ✅ Kezdetben ✅ Igen Szülő elem Rögzített fejléc

7️⃣ Top / Bottom / Left / Right - Pontos Pozícionálás

Ezek a tulajdonságok csak akkor működnek, ha az elem nem static pozícióban van!

📏 Hogyan működik?

Tulajdonság Leírás Pozitív érték Negatív érték
top Felülről való távolság Lefelé tolódik Felfelé tolódik
bottom Alulról való távolság Felfelé tolódik Lefelé tolódik
left Balról való távolság Jobbra tolódik Balra tolódik
right Jobbról való távolság Balra tolódik Jobbra tolódik
/* Praktikus példa: Absolute elem a jobb felső sarokba */
div {
  position: absolute;
  top: 10px; /* 10px a felülről */
  right: 10px; /* 10px a jobbról */
}

📝 Összefoglalás - Vizsga Tipp

Legfontosabb fogalmak

  • Block: Teljes szélesség, új sor
  • Inline: Csak szükséges hely, ugyanabban a sorban
  • Inline-block: Inline + módosítható méret
  • box-sizing: border-box használj!
  • box-shadow: offset-x, offset-y, blur, spread, color, inset
  • Position static: Alapértelmezett, nincs eltolás
  • Position relative: Eredeti helyétől eltolható
  • Position absolute: Szülőhöz viszonyítva, kikerül az áramlásból
  • Position fixed: Viewport-hoz rögzítve
  • Position sticky: Static → Fixed görgetéskor

🎯 Vizsga Tippek

  • Készítsd elő a * { box-sizing: border-box; } snippet-et
  • Rajzolj fel papírra a box modellt (content, padding, border, margin)
  • Gyakorolj position értékeket: absolute vs fixed megkülönböztetés nagyon fontos!
  • Box-shadow: ne felejtsd el a szintaxist (offset-x, offset-y, blur, spread, color)
  • Block vs inline: gyorsan felismerni és alkalmazni
  • Készítsd elő egy referencia HTML fájlt ezekkel a példákkal
⚠️ Gyakori hibák:
  • ❌ Absolute position-t szülő element nélkül → a viewport-hoz viszonyít
  • ❌ Inline elemre width/height alkalmazása → nincs hatása
  • ❌ top/bottom/left/right static position-nél → nincs hatása
  • ❌ box-shadow szintaxis rossz → nem működik
  • ❌ Padding-t kívülre számolni (content-box módban) → rossz méret jön ki
