Mini Vizsga - Kérdés 3

Kérdés:

Hogyan működnek a belső ugrólinkek HTML-ben? Mutass be egy példát az id attribútum és az <a href="#id"> link használatával!

Válasz:

A belső ugrólinkek szintaxisa:

  • Az elemhez egy egyedi id attribútumot adsz: <h2 id="fejezet-1">Fejezet 1</h2>
  • Egy linken keresztül erre ugrasz: <a href="#fejezet-1">Menj a Fejezet 1-hez</a>
  • A # jel jelzi, hogy ez egy belső link (anchor)

Teljes példa:

<!DOCTYPE html>
<html>
<head>
<title>Belső Ugrólinkek</title>
</head>
<body>
<h1>Tartalomjegyzék</h1>
<ul>
<li><a href="#fejezet-1">Fejezet 1</a></li>
<li><a href="#fejezet-2">Fejezet 2</a></li>
</ul>
<h2 id="fejezet-1">Fejezet 1</h2>
<p>Ez az első fejezet szövege...</p>
<h2 id="fejezet-2">Fejezet 2</h2>
<p>Ez a második fejezet szövege...</p>
</body>
</html>

Fontosabb szabályok:

  • Az id egyedi kell, hogy legyen az oldalon (ne legyen két azonos id)
  • Az id-ben általában kisbetűt és kötőjelet használunk
  • Az href="#" után azonnal jön az id neve kötőjel nélkül
